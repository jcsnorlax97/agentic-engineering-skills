# External Documentation

Specs, vendor docs, partner-supplied PDFs, legacy internal documentation — anything
in this project that's **reference material this project doesn't own the content
of**. If it was written by someone else (a vendor, a partner, a previous team) and
this project just reads/cites it rather than deciding what it says, it belongs here.

Not for: this project's own design decisions, plans, or grilling-session output —
those go in the story folders or `Grilling/` respectively. This folder is source
material to check against, not a place to write new conclusions.

If a file here turns out to be superseded by a newer version, leave the old one in
place (don't delete history) and note the supersession in `0000-INDEX.md`'s folder
map rather than only in this file — the index is where someone looks first.
