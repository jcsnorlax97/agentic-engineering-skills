# Candidate skill: idea-saturation-check

**Captured:** 2026-09-02 — vault-for-founders app-idea research session

## Trigger
Ran the same manual loop 13 separate times by hand while searching for a
first App Store app idea: propose a category, web-search for existing
apps in that exact niche, judge saturation, report back. 11 of 13 came
back saturated. The procedure itself was identical every time — only the
search terms changed — and was redone from scratch each round rather than
following a consistent, repeatable structure.

## Rule
A `idea-saturation-check` skill: given a proposed product/app idea, run a
structured saturation pass — (1) search for direct existing competitors,
(2) search for the specific differentiator claim if one is proposed (e.g.
"actually offline" vs. competitors' marketing) to check whether it's
verifiably true and not already claimed elsewhere, (3) report a compact
verdict: saturated / has-a-real-gap / infeasible-for-stated-scope, with
sources. Would have turned 13 manual round-trips into 13 much faster,
consistently-structured ones.

## Boundary
Only useful for consumer product/app ideas where competitive landscape
search is the right tool — not for internal tooling or infrastructure
decisions, which this session handled with direct source-reading instead.
