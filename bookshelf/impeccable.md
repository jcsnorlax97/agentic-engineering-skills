`/impeccable` Claude Code plugin for frontend design quality — 23
subcommands (`init`, `craft`, `audit`, `critique`, `polish`, ...), live
browser-based visual iteration, and 59 deterministic detector rules that
flag common AI-generated design anti-patterns. Also ships a standalone
`npx impeccable detect` CLI that runs without any API key.

Install: `npx impeccable install`, or `/plugin marketplace add
pbakaus/impeccable` inside Claude Code.

Surfaced in an Instagram roundup of 5 Claude Code repos. Relevant for any
frontend/UI work that currently has no automated design-quality check.
