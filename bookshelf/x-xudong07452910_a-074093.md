Summary of a Peking University paper (arxiv.org/abs/2608.20195) analyzing 557 real Coding Agent sessions and 33k+ Agent PRs: Agent-facing docs (AGENTS.md, CLAUDE.md, SKILL.md, plus self-left plans/notes/verification logs) make up 60.5% of doc interactions vs. only 1.3% for traditional API reference. 70.2% of doc reads are agent-initiated proactively; only 7.5% happen reactively after a failure. Code changes precede doc updates 4.7x more often than the reverse in PRs touching both. Argues AGENTS.md-style files are becoming new software-engineering infrastructure, serving both human and agent readers. Directly relevant to how this toolkit structures baselines/AGENTS.md.
